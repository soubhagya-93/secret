GELUU SURPRISE WEBSITE ❤️

1. Put this folder on your computer.
2. Create a folder named "photos" inside the website folder.
3. Put Geluu's photos inside it.
4. Open index.html in a text editor.
5. Find the "ADD GELUU'S PHOTOS HERE" section.
6. Add lines like:
   {src:"photos/geluu1.jpg", caption:"That smile ❤️"},
   {src:"photos/geluu2.jpg", caption:"Simply Geluu ✨"},

MUSIC:
Put your legally obtained copy of the Hum Tum audio in the website folder
and name it: hum-tum.mp3

Then open index.html in Chrome/Edge.

To put it online, upload the folder to a static hosting service such as
GitHub Pages, Netlify, or Cloudflare Pages.
